## Sheet: Sheet1

| Current Situation | Solution Descriptions | Problems other than it takes more time/development resources | Benefits |
|---|---|---|---|
| Players have very little incentive to move their bioframes around which is resulting in a static feel. |  |  |  |
|  | Incentive for Reaction Move: Ignore strike. If the player takes a Reaction Move and moves out of line of sight, then the shot fails completely. |  |  |
|  | Incentive for Moving: Dodge bonus. Bioframes which move gain a token which gives them a bonus to ARM.<br> | Makes fast/weak units just as tough as slow/tough units. Heavily bonuses fast units. | Units with large amounts of ARM are not incentivised to move as much. |
|  | Penalty for standing still: Dodge malus. At the end of the turn Bioframes which did not move gain a "Stationary" marker. Until they move, shots against them hit automatically. | Incentivises even further having more CP as this makes going first better. | Creates attacks of opportunity, which players can exploit by moving/firing. Gives more bonus for going first in Initiative, which normally would be considered a malus. |
|  | Every weapon has a very small range band in which hits are automatic. Players will want to move to be in this distance. | Without a move and fire action, this may devolve into players simply moving back and forth. | Could create interesting jostling gameplay. |
|  | Movement is a 0 CP activation. This also gives players without CP remaining something to do. | When would your opportunity to take this end? Can both players keep moving for free once they are both out of CP? |  |
|  | Add unit facing to Bioframes. Players will want to move in order to place strikes against the sides/rear of a tough target. |  |  |
|  | Force movement when shaken or hit. If the player must move S when Shaken or Hit, then they will need to move back into position. |  |  |
| Adaptive shot is very underpowered |  |  |  |
|  | Each weapon can only be fired once per turn, so firing with Adaptive shot means you can get the most out of a weapon in a turn. |  |  |
|  | Make Adaptive Shot more specialised rather than better. Adaptive shot allows the firer to decide what is damaged. |  |  |
|  | Reduce power of regular shoot actions. |  |  |
|  | Specialization. Add additional malus to the firer but make the shot much more powerful. Example: Using AS causes the firer to be Shaken, but the strike hits instantly at double power. | May promote the static gameplay that you want to remove. |  |
|  | Make adaptive shot cheaper. 1 CP activation. |  |  |
|  | Specialization: Adaptive shot is only usable in a tiny range band, but is better. This could incentivise players moving as well. |  |  |
| Objective Gameplay promotes standing still |  |  |  |
| Objective Gameplay creates situations where players cannot ever win. |  |  |  |
| Spawning of Drones, just for the CP reward seems very overpowered. |  |  |  |
|  | Increase the cost of spawning | Then there will be no reason to spawn them. Currently the main reason to as the payback period on CP is very short (3 turns) |  |
|  | Drones dont generate any CP | Spawning them is then every expensive. Losing a Bioframe is a huge disadvantage! | Focus on Bioframes increased |
|  | Bioframes generate more CP than Drones | Bigger numbers can lead to +1/-1 complexity | More room to move in the design process.  |
| Different types of Drone are vastly unbalanced. Ordinance and Infantry especially. |  |  |  |
