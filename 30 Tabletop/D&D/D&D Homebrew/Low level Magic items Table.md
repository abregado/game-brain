Item basics:

- Items must be in contact with the user for effects to be used.

Generation Method

1.  Consult the item rarity table

2.  Roll on effect table a number of times

3.  Roll on the Bonus and Penalty tables, rerolling until you have no duplicates.

4.  Recalculate/simplify charges.

5.  Add price to weapon or armour value, or see Jewellry size price.
