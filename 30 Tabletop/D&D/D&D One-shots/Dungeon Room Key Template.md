# Dungeon Key

One per dungeon.

## Things that need to be found

The story beats, key items and boss encounters should be listed here. Include some extra things that are optional to be used if the players are going very fast. Remember that at least 1 hour should be spent on the final thing. Each thing should have a visual aid, included at the end of the module.

Thing 1. Description. How it works. One example of how it can be resolved. Good choices for where to find.

Thing 2. Description. How it works. One example of how it can be resolved. Good choices for where to find. Does it rely on Thing 1?

Thing 3. Description. How it works. One example of how it can be resolved. Good choices for where to find. Does it rely on Thing 1 or 2?

Thing 4. Optional thing. What bonus does it give the characters? How is it relevant to the Final thing?

Thing 5. An npc. Include primary emotion, micro-feature when talking/listening. How much patience do they have? What do they want? What are they doing here? Add a printable image of the NPC at the end of the module.

Thing 6. The Final thing. Resolving this means the players are finished with the adventure.

## Combat groups

Lists of enemies that might be found. These can exist in a room, or appear after the characters explore the room. Prepare 3 different ones apart from the boss. Include images at the end of the module. Stat blocks go here, or make printable versions at the end of the module.

## Connector descriptions

For a five room dungeon you need to have at least 3 connectors. Try to Write 6 and then use them as you go. Each can be used more than once if they are effective.

Connector 1. Description. Difficulties encountered when passing. Effects on arrival. Equipment required to access.

## Dead end descriptions

There are always more dead ends than connectors. Use these for when a room exit should not lead anywhere.

## Global environmental effects

These should be applicable in any room and can be added and subtracted as needed to increase the tension. Weather, temperature, guards, ect fit in this category. These can also be applied to a single room to create more diversity.

Effect. Description. How does it hinder the characters? How does it assist the denizens? What signs are there that this effect is active (sound, sight, smell, ect).

# Room Key

## Room name/numbering

Leave it blank and let the players fill it in. They can use this to mark where exists are connected.

## Map/Visual Aid

A sketch of the map. This should include numbers showing the things listed below. It should be suitable for the players to see.

## Room Description

A narrative and cinematic description of the room. Include as many senses as possible. Include mention of each of the 5 things listed below.

## Numbered list of noteworthy things here

Always best to add 5 of these to every room. They should require a mix of abilities and have a range of difficulties. Use these to hide the Things from the Dungeon map. If a character succeeds then they get the thing, otherwise they only get the lore outcome listed. Each room should have something to discover that is not relevant to the dungeon key.

Noteworthy thing 1. Description for players. Ability needed. Difficulty. Lore only outcome. Things from the dungeon map that would fit here.

Note: If there are secret objects or doors, then draw them here and not on the map itself. Once they become visible, then have the players add them to the map.

## Exits

Always number the exits. Remember that the exits do not go anywhere specific until the players go down them. Then you decide what is at the end, and which connector or dead end to use. Remember, that two rooms might be connected with multiple paths.

# Appendix

Include images, stat blocks and maps here. Item cards with their rules can be printed as well.
