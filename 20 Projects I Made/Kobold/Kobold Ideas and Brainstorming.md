**New Gameloop ideas**

Choose vehicle -\> Undock -\> Explore -\> Find goal point -\> return to dock -\> change/design vehicle -\> undock -\> complete goal -\> Return to dock

Choose vehicle -\> Choose cargo -\> make run to any drop point for that cargo -\> return to dock

Choose vehicle -\> explore -\> activate locations -\> explore while waiting for locations to trigger -\> return to collect -\> return to dock (now heavier)

**What is the game loop?**

Choose mission -\> design vehicle -\> do mission -\> unlock progression -\> new missions and parts unlocked -\> Choose mission

Eventually no progress can be made without doing harder missions or getting better score on easier missions (the same thing?)

**Challenges**

Avoidance gameplay

Soft landings when carrying cargo

Moving physics objects without hitting environment objects

Cant have all the parts all the time.

Fine control

Control at speed

Returning to the top when full of cargo

Rearranging level objects to change paths
