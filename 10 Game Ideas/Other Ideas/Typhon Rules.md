<th><strong>Spore Miasma</strong>: Whenever an operative is shooting an operative more than 8" from it, roll one additional defence dice.</th>

<th>2</th>
<th><strong>Sentient Barbs</strong>: Whenever a player operative would move within 1" of a Tyranid Infestation terrain feature, roll one D6: on a 3+, inflict 1 damage on that operative. Only roll once per terrain feature per activation.</th>
</tr>
<tr class="odd">
<th>3</th>
<th><strong>Voracious</strong>: NPOs’ weapons have the Lethal 5+ weapon rule.</th>
</tr>
<tr class="header">
<th>4</th>
<th><p><strong>Synaptic Backlash</strong>: Select one player operative and roll one D6:</p>
<ul>
<li><blockquote>
<p>If the result is higher than their APL stat, subtract 1 from their APL stat.</p>
</blockquote></li>
<li><blockquote>
<p>If the result is equal to or less than their APL stat, select a different player operative and repeat this process.</p>
</blockquote></li>
</ul>
<p>This has no effect on player operatives that prevent any kind of PSYCHIC rules (e.g. PSYCHIC actions).</p></th>
</tr>
<tr class="odd">
<th>5</th>
<th><strong>Feed</strong>: D3 NPOs immediately perform a free Fight action. If none can, draw a different event card.</th>
</tr>
<tr class="header">
<th>6</th>
<th><strong>Overrun</strong>: Each NPO immediately performs a free Charge action up to 3" (its order can be changed to do so). Each that can’t can immediately perform a free Dash action instead.</th>
</tr>
<tr class="odd">
<th>7</th>
<th><p><strong>Lurk</strong>: Whenever a player operative is shooting an NPO, re-roll one of their defence dice if it’s appropriate for the NPO.</p>
<p>Whenever a player would strike an NPO, roll one D6: on a 5+, they must block instead. If this isn’t possible (e.g. it’s a normal success and the NPO only has critical successes), the strike has no effect.</p></th>
</tr>
<tr class="header">
<th>8</th>
<th><p><strong>Ripper Swarm</strong>: If a Ripper Swarm NPO isn’t in the killzone, set one up ready with a Conceal order in a location it can be placed wholly within NPOs territory in Joint Ops, or within control range of a random objective marker in Adversary Ops. In addition, place it within control range of a player operative if possible.</p>
<p>If a wounded Ripper Swarm NPO is already in the killzone, it regains all lost wounds.</p>
<p>If you cannot do either of the above, roll again.</p></th>
</tr>
<tr class="odd">
<th>9-10</th>
<th><strong>Birthing Sac</strong>: Set up one ready NPO with a Conceal order as close as possible to a randomly determined gestation sac (S) terrain feature. If you can’t, roll again.</th>
</tr>
