OWSC boiler plate tests

Basic

Go out and come back

60 seconds air

Increase to 90 120 and 180

Movement speed increase

Backpack size increase

Collect resources

Resources evenly spread across level

Clustered Resources

Same as 1 but very few resources are scattered

Instead resources are clustered around landmarks

One resource type per landmark

Food and water

Same as 1 but three timers of different lengths

Bomb timer

Instead of a oxygen timer, you need to press a button in the starter base every 60, 90 or 130 seconds

Build upgrades to make the timer longer

Systems that increase the timer max also require resources that slowly get depleted.

Those tanks can also be upgraded

Deploy and Return

Same as Clustered Resources but

You can't pick up items directly

Instead you place item collector s

Item collectors collect items until their battery dies

Player takes batteries from the base or to collectors and brings back resources

“Filling the empty trip” is the idea.

Base deployables

Same as deploy and Return but

Every deployable is actually a base addon

When within range of the base you can deploy any deployable that are associated with the base

Inventory is per base

Range can be upgraded in the base

Death overheat

Same as bomb timer but if you die, it costs about 10 minutes of timer to respawn you

Crafting overheat

Same as bomb timer but creating an item costs seconds of bomb timer.

Save bomb

Same as bomb timer but the game is only saved when you press the button
