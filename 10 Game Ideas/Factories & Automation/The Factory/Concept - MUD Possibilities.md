Situational Puzzle Game

Players are inside a factory/plant/refinery/ect

Each room has a number of inputs and outputs and machines

Documentation is kept offserver on how to run the factory

Players cannot “tell”, only local “say”

Inputs allow players to change setting directly, disable/enable machinery, change levels of material consumption

Outputs give players absolute readings on different variables.

Machinery performs a process. Eficency depends of a number of settings, inputs, materials used, ect

Tools are wieldable by players

Each tool allows certain commands to be given by the player

Only one tool may be carried by each player.

When a player logs off, all his tools are left on the ground

No major values should be able to be changed EI – set machine x to produce x litres of gas

All effects are managed by two inputs, some direct control, others are outputs from other machines

Set number of input types (oil, water, air, fuel, ect), size of pipe, conveyers, hoppers, manual entry,

Visual descriptors to give clues

By observing the system the system is changed (opening a pipe to measure pressure)

Screens and meters should be inaccurate, and sometimes faulty

Machinery and pipes need to be maintained or they will break

Broken equipment must be inspected and parts preplaced

Equipment should have stress levels at which damage starts occurring

The system should never be stable, but should be able to regulate heavy movememt.

Worst case it should just shut down if things get really bad
