To combat multi-accounts, griefer one offs and constant re-rolling of characters: Characters cost \$1 and 5 rerolls cost \$1. Player accounts can have as many characters linked as they like. If a character dies, it is gone.

OR

Client is free, but players who wish to run a server must pay. All servers run on a whitelist system by default. Application to a server has to be completed outside of the game. Official Server offered to everyone (open whitelist).
