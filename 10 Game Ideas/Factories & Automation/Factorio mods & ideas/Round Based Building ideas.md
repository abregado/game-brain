**Stacking to increase power but also access**

Characters can only climb up single blocks.

As blocks get stacked they increase in power

**Access only the bottom rung**

As you upgrade buildings, they get taller

You always access them from the bottom

**Mp roles/verbs**

Collect, rearrange, reset, assemble, connect, align, restart.

**Limited space**

Space for active structures is limited but unlimited unbuilt structures can be stored in a world inventory. Players set up production and then choose to run the game for a period of time.

**Forced no touchies**

Between rounds the machine runs without you touching it. You have to set something up that will produce a decent amount before it breaks.

**Items dissolve**

Resources come from the map but are unlimited in supply. The closer you are the better, as then throughput is higher.

At the end of the round, all items (not structures/machines) are destroyed.

**Building areas and quest list**

Give the player a list of goals to achiever inside a single round. As goals are completed unlock more complex goals.

The map has certain areas which can be used for building. Players need to assess each area and goal combination to find the best places to build.

Players are free to select which quests they want to attempt.

Round Based Building ideas

Game takes place in a room with a elevator. The player can request items to arrive on the elevator, and send items back down. The buildable area can be expanded over time. The elevator is an anchor in the world.

Game takes place in a forest which regrows every day. At night, you can exit from your cave and clear the forest to build a base.

Wattenmeer inspiration. Rides coming in and out, changing what you can do during each round.
