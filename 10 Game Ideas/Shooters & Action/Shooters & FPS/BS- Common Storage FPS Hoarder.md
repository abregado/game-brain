An idea for Unreals CORE framework, by Ben Buckton

Players start at the warehouse facility

There are a number of portals going to different worlds

Each day the worlds change and refresh

Resources in those worlds can be collected

Players can carry a limited (but substantial) amount of resources at one time

Returning to the Warehouse facility dumps all your items into storage

You control items that you add to the warehouse

Each week, a percentage of your items are “taxed”

Taxed items have their control changed to public.

Tax rate is determined by how much space you have reserved in the warehouse.

If you don’t have enough goods to “pay” your tax, then your reserved space is reduced.

The warehouse has limited space, shared between all players.

The warehouse always has an expansion project ongoing.

Anyone can contribute to the expansion project.

When the project is fully funded the expansion begins building

When complete, warehouse space is increased.

You can spend resources you own and public resources on upgrades for your character

Upgrades also take space in the warehouse

Each upgrade has a limited number of runs it can be used for

There are a limited number of upgrades a player can take on a run

Resources you own (not public) can be used to unlock new recipes for upgrades.

Better upgrades require larger resources, which are in harder worlds/areas, guarded by harder enemies, which require better upgrades to defeat.

The main upgrade is a respawn orb

When you enter a world, all carried respawn orbs are consumed

You gain a number of respawns in that world.

If you die with no respawns, then your character is deleted (all unlocks removed)

If you return to the warehouse with respawns still remaining, those extra respawns are lost.

The other upgrade is ammunition

This works similar to respawn orbs

Unused ammunition is not recovered when returning to the warehouse

Every other upgrade has a number of runs it can be used for.

A “run” is consumed, regardless if you used the item or not.

These mechanics should keep the server inflation down.

Players should self balance themselves by bringing less items

Players who are risk averse will bring more respawns, which makes progress slower but safer.
