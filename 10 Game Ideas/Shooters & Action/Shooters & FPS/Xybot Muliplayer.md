Server/Client setup

Client allows n players to play. Divides the screen into equal square viewports.

Each player can hold a “view map button” if more than one player holds it then the map gets larger

client options for map to be displayed forever

client can still join as zero players and just gets a fullscreen map

Server Features

- gridded areas with boolean states for walls

- characters

  - Powerup levels

  - differing sprites

- drop in, drop out

- select hero when joining server

- save all hero states

- only generate a new hero when a player joins and there are no heros available

- that player can select sprite/name of hero

- Enemy AI

  - move across enemy you can see

  - defensive rotate for turrets

  - try to collide for kamakazes

  - only move in 4 directions

  - minimum move distance before changing direction

- Terrain

  - Doors in walls

  - pits (no walking but shooting)

  - forcefields (no shooting but walking)

  - warp area pads

  - teleports

  - keys

  - areas which sap more energy

  - walls that can be shot

- Powerups

  - weapon supercharge

  - energy crystals

  - coins

- only send three tiles ahead to player

- Enemies

  - guard can shoot twice

  - turrets have side armor

  - jumpers move up and down

  - kamakazis ram you

  - service bots just drop things

Client Features

- select number of players to have on this terminal (0-max players)

- assign key controls (up to max gamepads + 2 kb players)

- test area for players to move around

- when all players enter the warp, ask for server address

- select always show map

- controls

  - show map

  - shoot/select

  - rotate left/right

  - move up/down/left/right

  - zap

Xybot 2d gameplay

several “rest zones in one level”

several teleporters on one level

each time a level is beaten the next one is more massive

eventually the levels become so big that many many players are required to beat them

procedural generation for levels

A max cap of coins that a player can have/spent on their character. Based on Level Progression

Players can join and play for free

1 main server with limited spots

Users can buy the game for 5 bucks and then start their own server

Their server starts on level 1

User servers cannot go higher than the master server level

Master Server resets when new content comes out

Players need to help the master server level up to access the new stuff

Random seeds for levels generated by the master server

Player equipment stored on the local servers

Players can cheat all they want on their own servers

We control the Master server so cheating shouldnt be too bad

Arcade style shooting means no aimbots

Maze structure means less Autobotting

Three heroes

- short red hair

- long black hair

- blond curly short hair

- All androgynous

Customizable Uniform for team identification

All powerups visible on suit. Some items visible only from side or back. Creates a showing off meta.

If players die then they go back to level zero and spawn back at the first safe zone

Players can store multiple suits but they dont carry over to the next level

enemy difficulty increases as players move away from the safe zone teleporters

Safe Zone/Shops become chat rooms and staging areas

Can scrap suit for ¼ money return

Gamepad and Keyboard controls

No experience from killing enemies. Explore for coins and bring them back to level up.

Enemy Types

- Side Armor Guard guys

- Big Mech guys

- Energy crystal guys

- Flying semi invincible dodging guys

- Wall Turrets

- Area defence Mini-bosses

Powerups

- Lose less energy from hits

- Lose less energy from environment

- Bigger energy tanks, and can drop tanks for other players

- More shots at once

- Faster bullet travel speed

- Reduced delay on firing

- More damaging bullets

- Faster Movespeed

- Map Scanner

- Enemy Scanner

- Player Scanner

- Teleporter Scanner

- Door Hack

- Warning Sensors (danger behind, ect)

- ALL DIMINISHING RETURNS

Terrain

- Pits that can be shot over

- Walls that can be seen through (Force Fields?)

- Areas which damage you more

Items and Enemies respawn if no players go in that area for a set amount of time.

Enemies prioritize players who are carrying more gold

Players must constantly push out from the safe zones.

Number of keys required to finish level goes up constantly so more and more players are required to be active.

**Differences to original**

- Energy Recharges to full when at safe zone (takes a few seconds)

- Players can create several Builds by spending coins on their suit

- They can swap between suits when in a safe zone

- They lose their current suit when they die

- Just one player getting through the level will spawn a new level

- Keys are per level. The doors are linked to the player who opens them. If they player dies then the door closes again.

**Level Design**

- Multiple different Tilesets for different areas

- Larger levels need more teamwork to complete

- Different teams of fighters need to be in different areas to keep the final door open
