#  Idea

Small CTF map for a Tribes:Starseige style game emphasising mobility

# Inspiration

- Previous Tribes maps and assests.

- Skate parks

- Castles

# Purpose and Features

This map is being designed to use as a testing area for a Proof-of-Concept modification utilising UDK and code supplied by projectfreefall

# Location setting

- Outdoor location

- combat between a mobile floating base and a ground base

- Hilly terrain

- Grassland or scrubland?

- Possibly a forested area.

# Photo reference

See directory for photo concepts

# Story

The players are either arriving aboard the floating base, or were stationed in the main base. The main base is protecting the local resource gathering operation. Resources could include:

- Solar arrays

- Communications equipment

- forestry work

- mining

- settlement

- shield generator

# Objectives + Obstacles + Set Peices

Each base is itself an objective and an obstacle. Flag stands will be placed in rooms with 2 walls closed to facilitate fast flag retrievals. Entrance/Exit points should be large enough that placed defences are not able to enclose them totally.

The bases should be quite close to eachother so that players can see both at all times

Halfway between there should be some landmarks to allow communication of location to teammates more easily.
