Extra axis to consider. Normally you consider the power differential between the player and the opponent above and below them. In a coop game you also need to consider the power differential between the cooperative players.

How much does any one player’s skill affect the outcome?

Are the end game and final challenges made to include all players?

Explore

- Map is revealed but only one layer

- All revealing cost resources

- Subway for starlanes

- Surface recovery expands out from metro stations

Expand

- Recovering access

- Eventually each faction wants to have their own location away from each other

- Enclosing the smallest possible polygon to achieve goal

- Each vertex is a player/team/faction

Exploit

- Get resources

- Resource management

- Tech tree

  - Research to unlock

- Reclamation rather than raw

Exterminate

- Spend resource to overcome challenges

- Defeat **active** opponents

  - Something static that regrows

  - Base defence Ala antarans

Faction special ideas

- Each ignores one resource mechanic

- Each can do one action for reduced cost: explore, clear, build

- Every faction can do every action

- Each faction has one unique resource that only their actions can generate

Tactical battle ideas

- When a battle happens, everyone has a battle at the same time

- Either multiple players team up in one battle

- Or each gets their own battle

- Each objective only gives one reward, but it is different based on who captures it
