Checked 2018 July

### Minecraft cooking

cooking website that treats cooking like minecraft recipes. Flowcharts and relationships with verbs. Each step is shown as a connecting line between ingredients.

2020: still want to do this

### ant pathfinding game

player selects tiles to dig and tiles to place dirt

ants move around and move dirt

some tiles are food tiles

if these are selected then ants will dig them and move them to the main hall.

player designates areas for food to be stored

### story campaign system (Broadstories)

nodes with dependencies

Nodes have a priority

Player can choose the node they want if there are two with the same priority available

each node has a time when it becomes available after its dependencies are met

each node has a time when it is no longer available after its dependencies are met

each node has a win/lose condition

node dependencies are based on win/lose

nodes are instanced to allow cyclical series (repeat mission until complete)

multiple starting states.

states merge in the middle

state splits toward the end into several endings

ship fixing game (conduit)

Minimum elements

- Terminal

- Power Core

- Switchboard

- Air Scrubber

- Air Vent

- Air Volume (Room)

- Door

Terminals are connected to Air Volumes and Machines

Air Vents are connected to Air Scrubbers and Air Volumes

Doors connect two Air Volumes

Switchboards are connected to Power Cores and Air Scrubbers

The player can only access objects that are in Clean Air Volumes.
