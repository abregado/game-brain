Island Combinations

Current Options

- each island has a one use part which is spawned at the start of the level

- each island has a small area 3x3x3 which is regenerated every 5-10 minutes

- each island can and should include a mob spawner in its regen section

- each island can include some rare resources in its regen section

- first get resources can be included in the initial section of an island
