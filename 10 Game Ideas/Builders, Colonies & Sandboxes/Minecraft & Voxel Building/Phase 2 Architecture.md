Examination of digital device access ability affect on spaces

Light switches go wireless, where would we put them?

Micro thematic networks

Landscape is how players are arranged

Structure are the constraints

Tools are the devices

Activities as nodes

Relationships just build up over time

The player can move to any node

They know the patients needs and build a 24 hour/ 7 week

Build one layer perfectly (or within 90%) to start next layer. First layer interferes with second layer. Continue with more and more layers.

Population signifiers (beds, desks) add congestion to utilities and services. Build. Structure organically which is successful and suports future expansion. “Capping” a structure scores it.

Some components change over time. This starts to sound like block hood.

Two phase game. First build a structure, then fill it. Wile building a structure you can see three possibilities for the second round and must plan for them all.

Each phase can have constraints. Footprint, connection to other structures.

Build chunks of a structure in isolation, then connect them in a different game mode.

Competitive layer. Players build spaces which are unusable, others try to use a random set to create something useful.

Players have a team and get points for there being more of one thing in the level. No destructive gameplay so the only way is to build more.
