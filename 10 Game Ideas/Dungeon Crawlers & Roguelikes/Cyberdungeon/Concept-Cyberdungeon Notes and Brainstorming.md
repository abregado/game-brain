Cyberdungeon Notes and Brainstorming

Abilities provide a passive bonus and a Heroic Active bonus/ability

To activate a Heroic Ability, you must remove one of the OTHER passive abilities

Experience

Every hero gains ONE new thing after each adventure. Whether it is a new ability card or a new characteristic/discipline card.

Character Rotation (Option 1)

At the end of each mission, players add the level up they feel is nessesary. Then characters are notated to new players. A player should never be in control of the same character for two games in a row.

Character Rotation (option 2)

Players may play the same character as often as they like. The other party members select that characters experience upgrades for him. Players are welcome to change characters before the next mission.

Question? How to make the players have a vested interest in their survival, while still controlling the enemy themselves.

Option 1: Mook creatures are placed under the control of the chracters directly. Rules will dictate how and what they attack, and where they can move. Each ability or action that a Mook creature can take generates Tension Points that can be spent by your player on special actions and abilities.

Mooks must attack if able to do so

Mooks must move if unable to attack

Option 2: Each player is given a number of Initiative Chits. Some green and some red. Players spend green tokens to perform actions with their characters, and spend red tokens to perform actions with Mook creatures. A player may never spend a green token if they have more green tokens than red tokens. This ensures:

Players can act before the mooks at least once

Ambush situations can be easily modelled (give players more red chits than green ones)

If not all characters are involved in combat, only characters in this combat are given red chits. This allows characters outside combat to re-enter very quickly as they can act without spending red chits.

Players will interrupt if possible to ensure their character can have his turn.

Spending turns setting up attacks, or using special abilities to ambush Mooks can reduce the number of red chits handed out in a combat. This allows the heros to take on numerically superior or super fast enemies without making those enemies incredibly crap.

Initiative Order (Option 1)

Each action has an initiative number associated with it. When this action is performed, other players may “interrupt” the action by using another action with HIGHER initiative number. These values are 1-3. 3 being uninteruptable. 1 almost assuring interruption.

Ranges (Option 1) ake State Tokens

Each room is an entity. Models in each room can change state to be:

At Range

Covered

Close Quarters

Hidden

Each feature card sets a maximum number of models that can be in each state. Each weapon has a “perfect” range state for the target to be in. Also, special attacks may require the hero to be currently in one type of state.

Ranges (Option 1) – keeping range and concealment separate

3 Areas: Same Room (Mid Range), Different Room (Long Range), Same Feature (Close Quarters)

Models that are on a feature gain states listed on the card. Some of these are:

Covered (4+ to hit. Or cant hit if in non-perfect range), Hidden (cant be hit), Exposed (Always clear shot)

Each action allows a model to move once:

Between two features in the same room

Into or out of a feature in a room

From one room to another room (but not into a feature in that room)

**Keeping the pace (the time element)**

I would really like to think that more than one combat will take place in each adventure. I feel that definable end points are COMPLETELY necessary, especially in this sort of game.

The game outside of combat will be broken up into single “Exploration” rounds. Every time a character spends an “Exploration” round, the environment becomes more hostile.

Option 1: Danger increases based on number of heroes acting

Each time an individual hero acts, a single token is added to a pile. At the end of any Exploration Phase, the heros can decide to spend these on a Situation Change. The most expensive type of change is always used (and tokens removed from the track to the same value).

Plot Cards

Each plot card adds to the maximum Threat rating. When the Maximum Threat is reached, turn over a plot card. This spends the Threat, but also increases the max. Some examples include:

Something Else is here (+3max). One of the heroes finds some disturbing evidence that an alien creature is onboard. Draw an Unknown Minor Encounter. This encounter will occur instead of “Combat Ensues”. Play this out immediately as well.

A ship approaches (+3max). Our ship has detected another vessel incoming. Once it arrives our craft will have to break off and flee, and the enemy will receive rein-forcements. (time limit). Players must return to the ship or stay and fight A LOT of dudes. Ignore this card if it is the first Plot Card

Alert! (+5max) The Mooks have been warned of your presenece. When they move now they will always move to each feature before moving to the next room.

Things are getting tense! (+10max) Increase security by X

Survellance (+4max) The enemy are using the ships surveillance gear to monitor where you are. Your party is detected unless it stays in cover or is concealed. Ignore this unless the Alert Card has been played.

Automated Defences (+5max) The enemy uses the ships hidden automated defence system to attack you. Heroes are attacked every turn they are in the current rooms. Technical Skill to remove this, while in an effected room. This effect is ignored if the Surveilance card hasn’t been drawn.

False Intel (+3max) Some of your ship scans were incorrect. Crew +5

The Darkness Stirs (+6max) One of your heroes glimpses something in the darkness. Whatever it is, its becoming more hostile. Draw an Unknown Major Encounter to replace the minor encounter. If you have not drawn a Minor Encounter then ignore this effect. Play this out immediatly

The Full Horror (+max) The unknown creature reveals itself for combat. Draw an Unknown Boss and begin combat as described. Ignore this effect if a Major Encounter hasent been drawn.

Specials for Rooms and Features

Expansive: all features in this room have +1 Occupancy

Cramped: all features have -1 Occupancy

Cover: Units in this Feature or Room count as being in cover

Hard Vaccum: The room has no life support

Obstructions: All damage dealt in this room is reduced by 1

Terminal (x): The terminal in this room allows for remote access. X is how many units can access at once

Master Terminal: This terminal allows all systems to be overridden including other terminals.

Manual Control (System): A unit may interact with the listed system here without being interfered with via terminals.

Vent (x): units may use vents to move throughout the ship. X is how many units can move per turn.

Cargo (x): there is a number of commodities here. Deal this many commodity cards out.

(Door) Lockdown: This door can be sealed mechanically

(Dorr) Security Code: This door can be sealed Electronically or via a Terminal

Special Behaviors for Mooks

Hunter: will always attack the hero with the lowest HP

Prize Fighter: will always attack the healthiest hero

Alert: must be the first Mook to be activated

Detector: Combat is initiated if Heroes are within the same room

Cowardly: This Mook always runs after combat

Pet: This Mook always runs if there are only pets left after combat

Bitter End: This Mook will never run from combat
