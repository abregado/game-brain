Brainstorming

Cyberdungeon Space dungeon crawl party advancement ideas

Steve mentioned he hadent heard of a game doing this so i'll write it down before I forget.

This should workon both tabletop and computer systems but was concieved for a computer system.

The characters and party details are persistant on the game server. The hosting player selects to use a resaved party, or start a new one when he Hosts a new game.

Other players join in and can select a character from the list of available crew members. They cannot use characters from other parties they have stored locally.

The mission commences, each player controlling his one character for the duration.

Experience earnt is applied to two pools. First there is a pool for each character, which the player may spend to upgrade that character after the mission. Secondly there is a larger pool which the host may spend on any character, or give to other players to spend on their character.

After each mission the players rotate which character they use (or there is a server setting for fixed characters).

This should reward players with the "community building project" feeling. They are all adding to the atmosphere and setting by playing and selecting upgrades. This should balance each character as they will not be so focused with many people using them. Public servers will have much more evened out characters.

As the amount available for personal spending is limited, greifing by messing up a character should be minimized.

Public dedicated servers should have their "party pool" points saved until an admin logs in and spends them.

The limit of characters in a party should be a "soft limit" and not simply be the same number as the max players per mission. This will give all players a choice as to what they wish to be.

The first player to join (or the host) selects their character first. As players join they get dibs on the remaining characters. There should always be more characters than players so the last player still has a choice.

Perhaps if there is a way that characters can be killed, or leave the party of there own accord (personal goals?) the max player count could always be one less than the number of characters in the party.

Party Points can be spent to recruit a new character to be added to the party.

Equipment can be either fixed to a character, or available in a Party Armory for selection before a battle.

Parties should always have more options than they can take into a mission.

After a mission, the players all complete a "post battle" session before the next mission becomes available.
