A single adventure is a series of conected challenges. These can be:

- combat

- skill checks

- check to skip next challenge

- time dependant challenges

- risky opportunities

- requirement for stealth

- item use

I number of Keywords will be required to link challenges with objects and abilities.

Cyberskill

Technical

Intimidate

Stealth

Mobility

Resistance

Suspense Level

In this setting every turn makes the eventual encounter harder. The players work to trigger the event early or try to finish the objective before the event happens.

Heroics

Players may spend stored Heroics points before making a check to automatically pass it.

Combat Length

combat needs to be very fast. since there should be several combats in a regular game or a single, long combat.

Limited Resources

Heros have very finite resources. Every item only has a number of charges, every ability only has a number of uses. players must complete the objective before they run out of resources.
