## Played on Grid

Match 3 or more

Draw line through all of same type (orthogonal or diagonal)

Slide vertical or horizontal line

Slide tile into empty space

push marked tile off edge of board

Tiles stacking and changing (2048)

Tiles sticking to one another

Tiles have orientation

Beams projecting from tiles in multiple directions

Flip all adjacent tiles

Tiles have value, must add up correctly in rows and columns

Tiles can only have so many connections

Some tiles connect, some are sources, some are goals (oilwell)

Tiles give information about their neighbours (minesweeper)

Tiles must be in ascending or descending order

One of each of a set must be in every row and column (sudoku)

### Node Based

Each node has a fixed number of links

Each node can only be linked in a number of directions

Nodes have orientation

Nodes have height

Nodes connect only to same color

Nodes have line of sight

Nodes can move along one axis

Links can only be between Nodes of the same color
