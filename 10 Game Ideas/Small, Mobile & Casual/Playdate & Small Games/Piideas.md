Unique features of pii

- Portable

- Loungeroom gaming

- Players feeling of ownership

- Local display

- Input outputs

- No dependancy on 3g for muliplayer

- Open source (lots of libs)

- Headless

Take advantage of

- Unique usb input devices

- Mesh/adhoc networking

- Works with lua

- Pick up games with strangers

- Kepps running while not connected to a display

Limitations of games

- 2d only

- Possiply have to move to python.

- Graphical limitations

Types of game that would suit

- Slow city builder

- Management games

- Farm games

- Tick based

- Trading games

- Adventure games

Actual ideas

- Realtime RPG/action game. Your character acts in realtime and then must recharge while you are away from the game.

- City builder that cannot be paused by the player. If a major event occurs the game pauses an an external led is turned on to inform the player that attention is needed.

- ball physics game. each player that joins adds a ball to the stage and can only deflect other balls

- use gps data from connected devices to place game objects into the world.

- each player only sees a part of the game world

- the server gives players monsters to fight, dungeon based on each players device in combination wih the servers data.

- splitscreen hdmi output, web devices as controller s

- audio output explaining events and players react to the information

- player info is stored on the server, but displayed on the players device.
