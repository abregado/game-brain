Constraints:

- No accounts

- All players can control everything

- Update gamestate only when someone requests to view the state

- Simple addative gameplay

- Persistent world-state

Aims:

- Promote players checking on the game

- Promote more players watching at the same time

- Show players how many people are watching

One turn passes every ten minutes.

Each session can make one change per turn

Store up to ten moves

Each move let's you spend some resources

Resources spent on searching for new base locations

Resources spent on building new bases

Resources spent on upgrading bases

Resources spent on moving resources

All resources are communal

Limit rate of expansion by limiting number of new areas to scan

Resources should be interchangeable

Processes consume resources and then take time to finish

Callbacks produce new resources

Ships, tools, sensor signatures, bases are all resources.

Maintenance costs are automated processes which auto repeat

Other build processes must be player initiated

Missions can use variable amounts of resources for different payoffs

Missions initiate other missions to return material
