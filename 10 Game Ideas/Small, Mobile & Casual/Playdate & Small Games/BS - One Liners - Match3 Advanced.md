- A match three where the goal is to fill up the board

- A 3d match three where you can rotate a sphere containing the ‘gems’ to build new paths between them

- Non-grid match3 (hexagons, nodes,cubes)

- Matching items creates new ones which create new ones, ect. How far can you go with the same starting materials.

- Matching items splits them into more materials than were before

- Certain gems react when left next to others for too long

- Try-not-to-Match3 where you rearrange Gems so they don’t react or are not next to any others.

- Gems move by themselves when a timer hits zero

- more than one effect from matching, selectable at bottom of screen (fire, ice, air)

- Gems move along a predictable path after each match (not just down)

- Gems are not fixed into a grid, but are placed in non-discrete (continuous) units.

- You can select 2 matches to pop at the same time

- Matches pop ONLY if you match 2 or more sets

Challenges of match3

- Visualization must be 100%, no hidden areas

- No randomization of effects

- Juice requirements: gameplay is basic so the visuals must be fantastic

Benefits of Match3

- intuative

- flat learning curve
