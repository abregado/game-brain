**Base UI**

Harvesters/Pads/Carryalls

Show all teams Spice per min to see whose eco is winning

Minimap just more clear

Show paths between rocks

**Building Shortcuts**

Quick build structure in nearest available space

Squad makeup selection

Rebuild/queue reinforcements in one button

Enable/Disable spice fields for auto selection

Recall/Send all harvesters toggle

Place buildings as blueprints

- Blueprints get a priority number

- Left click to increase priority

- Right click to lower priority

- Right click priority 1 to remove blueprint

Send cash to ally

Building upgrades directly on the building or Construction Yard

Auto build windtraps

Auto repair (to promote raids)

Set retreat point

Build fortifications per rock

- Walls and light turrets all the way around

- Heavier turrets on ramps (maybe upgrade ramp defence level)

- Replace rocks with tank traps and bunkers

**Unit Shortcuts**

Seek Cover

Return to base defence positions

Units attacking something they can run over always try to

Units always get placed into a squad near to the factory

Once a squad has had custom makeup set, it no longer accepts new units

If no squad near the factory, make a new one

Max 10 squads

Disband a squad to have its units return to the factory

Move/Order by squad number, so you can set up a patrol that will be automatically reinforced

Attack move

Patrol/Defend rock platform (region)

Set rock as home base (retreat point)

**Gameplay changes**

Worm picks a field and inhabits it for a while

Spice regenerates after worm leaves

Spice field is disabled while worm is in it

Units path around disabled fields

Storm effects one rock platform at a time, and never one with a base on it.

Native settlements give money over time for map control bonus

Much lower damage on troops in cover/rocks/tank traps

Higher time to kill on average, speed penalty for being hit
