Pillars and Paradigms

- The system only updates when it changes

- Minimise the number of instances that store state

- Minimise the number of objects that have per frame logic

- Player reacts to delta with changes to their delta

Screens

Classes

Requester builder class: Bucket

Consumes Infrastructure resources to fill itself.

When full it spends all the infrastructure to adds a requester that consumes the most required resource (if there is one), if it is still needed. Then it picks the next most required resource and decides what it will build next, setting the bucket max.

If no needed raw resources are available, but removing a requester would help, then it does this.

Commerce and Infrastructure builders as above

Commerce requesters consume one Labor resource per tick (plus thier inputs) and cost Finance in a bucket to be built

Infrastructure requesters don’t consume anything (apart from their inputs) and cost Infrastructure to build

Each has a widget to how percentage until requester complete

**PressButton: Widget**

Button to activate effect and empty bucket when its full

**AutoEmpty: Widget**

auto empties, on/off toggle to let the bucket empty itself

**Non-interactive bucket: Widget**

Just shows the bucket level

**ResourceGauge: Widget**

Show for each resource the income:request ratio

**ResourceGoal: Widget**

Let the player set the goal amount for a resource. Used by the Builder classes to determine if they should build, destroy or change requesters.

**PlanetInterface: Widget**

Two buckets. One for pop growth, one for pop max. The pop max bucket can be toggled to stop growth.

**Exploration class: Bucket**

Fills with Exploration resource. When full it generates a new Wild resource. Utilisation modifier is random but slightly higher than the average on average, so that modifier trends upwards.

**Colonization class: Bucket**

Waits for a Planet resource. Picks the cheapest to utilize planet resource. Fills with Pioneers resource and Infrastrucutre resource. When full, adds:

- a new Colony bucket class

**Colony class: MultiBucket?**

Consumes food into a bucket. When full if there is space, adds a Food resource requestor that produces Labor (population)

Keeps track of all its requesters.

Has a maximum number of these requesters (population). Consumes infrastructure to a bucket to increase the maximum (to one higher than its population)

Each next pop costs more food in total (double?)

**Research class: Bucket**

Consumes science resource. When full, gives the player a choice of flag to add, which enables requesters and wild resources.

**AutoStartRequester: Requester**

Just a requester that requests nothing and produces 1 exploration and 1 infrastructure. Can’t be disabled.
