Stardrive buildup multi layer game ideas

Abstract, removed perspective city builder. Multiple cities on a planet, but player only controls one.

Uncontrollable variables:

Population  
Unrest  
Special Resources available

Controllable Variables:

Workforce allocation  
Taxation Levels  
Structures  
Morale – indirectly  
Birthrates - indirectly

Features  
Turn based  
Multiple demographic types (species, races, classes)  
Players change policies instead of having direct control.

Structures used to provide bonuses to populations (Housing, Entertainment, Power, Logisitcs, Commerce, Industry)

Special Locations/Resources can be exploited by building specialist buildings.

MILITARY

Military value is equated from Enlisted Men x Equipment/Training Value.

Specialist Units/Commanders are built from Specialist structures using resources.
