Breaking It down

Start with the smallest piece that can be visualised and get people interested.

City Generator

Time based growth of cities

Realistic expansion based on primary industry

Population, pollution, land area, buildings tracked

Planet Generator

Realistic planet properties (size, weight, biomes, atmosphere, composition)

Random Heightmap generator

Continents and liquids modelled realistically

Integration with city generator

Solar System generator

Determines number of objects and properties based on age and mass

Sun lifetime modelled as realistically as possible

Integration with Planet Generator

Stellar Object Generator

Range of generator options (asteroids, comets, planetary rings)

Orbits and flight paths

Slaved to a planet or free floating

Generator Client

Application to generate random or seeded solar systems.

Specific Inputs when wanted

Results can be edited and fine tuned

Systems can be saved for later

Application to view generated solar systems in great detail

Basic 3d graphics required

Single Player Flight System/Client

Moving between stellar and local objects

Basic flight GUI/HUD

Basic Controls (mouse controlled, fly to command)

3d stationary objects (planets stations) in space

Sprites and vector lines for ships/moving objects

Realistic and Relativistic Speeds

Acceleration/thrust mechanics

Inertial mechanics

Integration with Generator Maps

Intermediate controls

More advanced GUI

Basic Flight pattern functionality (orbit, distance, follow, elipse, match heading, formation)

Control Points

Controlling more than one ship

Changing which ships are controlled (exiting/boarding ships)

Network Accessibility

Dedicated Server

Client

Multiple players on one server

Login and Security Scripts

Chat

Basic Activities

Item Tracking

Cargo system

Trade containers (moving objects between ships)

Docking with objects and other ships

Formation flying, and formation control

Currency

Manufacturing System

Factory ships

manufacturing processes

Input/Output containers

Deploying facships (just gives resources over time when deployed)

Fuel Ships generate fuel points

Mining Ships generate resource points

Manufacturing ships use mfg processes

Basic Combat System (players)

Combat between player ships using Flight Patterns

Expendable ammunition

ship health

very basic mechanics (DPS, range and firearcs)

Basic Combat AI

Copies successful Flight Patterns based on kills while using said pattern.

Starts with a base set of patterns

Selective targetting

Generic enemies in ships (spites required)

Server controlled NPC's

NPCs spawn based on number of facships deployed

Complex Locations (space stations and planetary locations)

Advanced storage system

Ship hangers

Shared hangers and storage

Currency/Full Trading mechanics

Players can trade items and ships between each other

Initially all players only sell to the server and the server sells to players based on supply.

Player run auctions/ items for sale listings

Trading GUI

Remote cargo GUI

Open Testing

Servers pay subscription/ or for updates

Players can pay for a verified account

Servers can use verified account to track players between servers

Servers may accept both verified and unverified players.

Advanced Combat System

Speed, Size, accuracy, missile tracking, turret speed, targetting subsystems, different weapon types, different ammo types, Armor types. Ablative and resistant armor. Speed bursts (afterburner), making it look dogfighty, targetting mechanics, scanning enemies, disabling engines. More flight pattern options for formations and attack vectors

Damage system. System damage, effects, DoT, area effect, heat damage, effectiveness loss

GUI to suit. Fast flight path selection, automated target selection, emergency jump, self destruct

Advanced Mfg System

Ship design, detailed processes, customisation, branding and prototyping, integration of different ship types, Input/Output containers with buy/sell values as well as cargo templates.

Advanced Resource Collection System

Scanning of assets, exploration, complex exploitation requiring skill, reflexes and knowledge. More than one player required to complete any one chain. Ships with specific roles. Mini professions. Asteroid mining, refining, gas collection, solar/other power collection.

Advanced Market and Job System

Setting of orders to buy OR sell

Customizable, BINDING contracts to be given to other players

Many options for contracts

Many payment options

instant trade, round table trade, taxes, Cargo area and Hanger fees on space stations
