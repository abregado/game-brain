BS - Infinite point pathfinder game

Multiplayer

Infinite field of star points

Fuel refills slowly over time

Explore new systems while keeping an eye on your fuel

Build fuel refineries

Set up autopilot “over time” shipping from nearby systems for resource import to keep your fuel refineries going.

Set up a toll for players exiting this system on autopilot

Find systems which have refineries to create autopilot routes
