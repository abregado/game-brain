Bs - class based building game ideas

A robot which constructs objects in a room if there are suitable resources in the room, it has power, and someone activates it.

Setting up what it can build, it's range, cargo allocation and tool options can only be done by the robotist.

Every machine built needs power. Anybody can have a machine built by the robot, but the connections must be made by the electrician. Anybody can plan the connections but the electrician needs to actually place them.

When damage occurs, cables are broken. Anybody can repair a connection to level zero, which has reduced output and further tendency to break. The electrician can repair these properly up to full throughput.

Obvious things:

- Furnace/smelting

- Changing shape of substance

- Breaking down items

- Mixing and separating gasses

- Constructing components

- Storing items for a given period

- Housing guests

- Refuelling passing ships

- Processing data

- Retrieving dropped space objects from surrounding area

- Suffer an event for money

- Build Power Generation

- Recharge batteries or fuel cells

- Repair a large component

- Create or process biomass

Not so obvious things

- Detect asteroids that will impact near your base

- Lasers that can push asteroid impact sites away

- Build shaded areas to grow plants under

- Temperature regulated areas for storage

- Large rooms give a buff to players

- Rooms with lots of equipment give larger buffs to players.

Profession ideas

- Botanist

- Bartender/Chef

- Robotist

- Chemist

- Surgeon

- Metallurgist

- Geneticist

- Beaurocrat

- Machinist

- Data specialist
