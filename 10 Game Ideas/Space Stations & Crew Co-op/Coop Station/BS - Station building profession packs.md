BS - Station building profession packs

Rough idea: force the player to play as multiple characters, each which interact with the world differently, but which build systems that must be interacted with differently by each class. Each time they play as one class, they should discover something which they built with another class, that could be made better for their current class.

Example: playing as the electriction, the player knows no other classes can repair wires, so sets up fuses which blow instead and are easily replaced. Then they play as the admistrator, and need to replace a fuse only to realize that all fuses look the same to the administrator.

Players have multiple characters and are forced to swap between them during play.

Survival stat: sanity. Basically a time limit on how long you can play this character.

Regained slowly when not being played.

Players can call a retrieval shuttle at any time to swap characters.

Every character can build, but some have special crafting recipes, and can operate particular machines. Players must build a system which is usable by all classes during a crafting session.

Some crafting requires two different classes or more, so either multiplayer is necessary or intermediate storage of half crafted items is needed.

Profession packs are the DLC. Each provides a job tree, some machines and items, which work together. These all are integrated with the base classes, which focus on base building.

Each profession inherently adds a new goal to all players bases, if they want their base to support that dlc.

When designing we should think about which classes a new class depends on and which this class generates work for.

Design questions for each class.

What is it that only this class does?

What do they need other classes to do for them?

How do they create work for other classes?

Base classes:

**Electrical**: can operate and modify settings in power machines, check, upgrade and repair cable connections.

Must set up fuses for others to replace. Others cannot control electric system directly so must set up basic controls for electric devices.

**Mechanical/Atmo**. Operate and modify settings in mechanical machines, such as pumps, furnaces, hydraulics. Can upgrade, repair and check pipe connections.

Provide simple controls for other classes. Systems require readouts since other characters cannot read these values directly.

**Processing**. Can control, configure and reset building and transport robotics. Can repair and reprogram Robotic units tasks.

Others can only start or shutdown robotic units, maybe move them around. Setting up each type of robot for a type of task and seeing it's parameters is necessary. Automated deliveries to different areas are also necessary because many basic intermediates cannot be simply crafted by other classes.

**Admin.** uses terminals built by others. Can only do basics of building and repair. Accepts tasks, hands in jobs, inspects cargos and does trading. Can prepare objects for being upgraded (beaurcratic oversight). Hates to wear a space suit.

They might be able to complete some tasks on Thursday item if the bar is set up to allow it. They generate work for others by accepting jobs and assigning places in the hanger for materials, ingoing and outgoing.
