Randomize a set of rooms in 2d.

Each wall section has a type:

1.  Unbreakable (outer walls and a few inner walls, cant be removed or destroyed)

2.  Cuttable

3.  Empty



Rooms are generated with a lot of wreckage which blocks movement and placement of new objects.

The players start in one room and explore/expand outwards in rounds. Starting resources come from salvaging wreckage that is generated when the level is made.
