Cold sleep Crew

I want

Base building and crafting

They also have good revenue potential

But

That normally takes place in an open world

But

That is expensive!

Plus

I only have two people working part time

So

Let's use a closed world

The player is given a set of rooms with machines and typical crafting game stuff along with a set of item requests they need to fulfill

They need to rearrange the objects into a function setup and then return

This is typical base building gameplay

Then the cycle continues

We can gate the content and progression using this method

These round based games are really in at the moment

There is a lot of interesting ideas to explore with but I don't have time.
