A git-like Chat program where you can fork the conversation at any time. Generates a new channel with a duplicate of the history. Users can mark where they think this conversation began.

Single control station game. Player is controlling a single job station on a spaceship. Isolate some simple mechanics and then abstract everything else away.

- Docking controller

- Shield monitor

- Weapons coolant

Top down space game where you can’t control where the ship flies, only what it shoots at.

Turn based maze exploration game.

Reverse Tower Defence. Place things down so that enemies CAN reach the power cores and get out alive.

Collectable categories. Easy to get one item from each category, but hard to get all items from a single category.

Drop blocks and then push them aside. Compactor!

Node connections to access material lumps nearby. “Organ” nodes request materials from the lumps, they get transported then converted. “Pull” logistics. Waste products? Where is the challenge.

Lander Game with Wind

Lander Game with Pulse engines only. Each ship has a number of engines, each engine has a key. Hold the combination of engines and press space to fire.

Alchemy Game. Grid of workspace. Placing items next to each other makes them react eventually. 4 Options for effect on sidebar: Heat, Cold, Pressure, Vacuum. Each affect cauldron can take 2 ingredients and creates different things. Objects are taken out of cauldrons and placed on the grid.

Biocell game. Grid based. Cells move by themselves and react if they collide. You can only create new cells in the centre of the screen.

Falling blocks in a number of columns. You can only swipe each block once into an adjacent column then it falls down. Combinations disappear as tetris.

Circular blackhole tetris. Rotatable center piece. When a whole layer is added then the piece shrinks. More than one new tetrimino is falling at the same time.
