Easter train dump 2

Bauspiel/building game

Make a machine and then operate it.

Round based, but why?

- Shouldn't feel forced

- Player should want to make the rounds shorter or at least fit

- Machine only runs when player is not playing

- Gameplay is setup then points come afterwards

- PreSet levels, but player has a time limit to change things. Less time used means more time to cook

- Playing must unpack but time in setup is not counted.

Concept 1

See the level and plan by placing machines.

Machines are then put on elevator and setup is part of the cooking gameplay.

Max stars only reachable if you pack up properly.

Dealing with persistence

- Multiple Save states that get harder

- Reset after a run

- Push to unlock new map that is "better"

- Some other way of making the player want to restart

- Each tier is exponentially better

- Progress is banked in a second layer

- Don't have persistence

- Time takes is toll between rounds

What is a round

- The sweet spot where the town is rich enough to grow and poor enough that corruption had not set in.

- A single adventure

- A round trip

- A generation

- A job shift

Diggy diggy couch coop

New game elements appear at fixed rounds

Save game eventually becomes unplayable, player needs to restart.

Concept 5

Catchy catchy

Then any player can catch the monster

Concept 6

Travel together between locations

Collect and plant along the way

State is saved for the next trip on this route

Help people with mini games/quests and get the rewards next time you pass

Quests can be repeated, but don't always reset

Limited inventory between locations

Concept 6 expanded

Privateer/vegastrike type game

No direct flight control

Each trip has a number of stages

Each stage has random events that can happen

Each player chooses a ship and buys cargo+equipment

At each stop the player can swap ships

Not all ships are available at all stops

Before leaving, a mission budget is shown

Events are time sensitive

Resolution via

- Options menu with costs

- QuickTime event

- Combat system

Events

- modify how protected the convoy is

- Give a chance for a bad event later at a given stage type

Concept 6.2

Top down.

Players can move between towns quickly.

They can send caravans between towns

As caravans travel, they might get attacked

Players must intervene to deploy protection

Town selection

When in a town there is a radial menu to do things

Holding the trigger brings up the travel menu

The letter then hold the stick in the direction they want to travel and releases the trigger.

If there is something along the way, your view guess there, otherwise you end up in the next town menu.

Town development

Towns have requests to level up

Towns slowly decay to a lower level

Each town produces certain cargos

Each level up requires certain cargos to be delivered.

Goals?

- Stability?

- Max a town level

- Survive a repeating crisis

Monster catching

Travel between locations and leave monsters in breeding centers to come back later to.

In a town you can decide to put wild monsters in breeding, storage or taming

Caught monsters need to be put somewhere or released when you arrive in a town.

More players just means more chances to catch and explore

Maybe certain paths are only accessable with more players

Monster tree, once you have bred a monster it is available any time from a breeding centre

No monster fighting, only collecting and breeding

Sammelspiel

In the centre is shown what is needed next.

Player can choose tools

Time limit that you can be away from the center

Collect and return

Each level up increases range and capacity.

It's simple, but is it effective?

Paths are left behind mechanic maybe fits here?

Alien world lumber jacks

Start in a forest

Cut trees to make space

Lumber is cheap to build with but will not last

Forest is surrounded by plains, making construction more costly.

Player do

- drive trucks to move resources around

- Place new buildings

Automatuon to fill parked vehicles

Vehicles are ordered from orbit at regular intervals

Shipments are collected at regular intervals and taken to orbit

More players means more vehicles in motion

Topview or third person would work

Crashes just reduce cargo.

Vehicles are invincible.

Construction happens within range of the construction vehicle which is very large.

Scout for resources

Build roads for the larger vehicles

Other robots

- Build player spawners, which let players teleport between them.

Infinite level? Generated and hand finished is probably better.
