# BenGameBrain

Ben's game design brain: about 720 documents from the *Game Stuff* Google Drive folder (2010–2026), converted to Markdown with the original text unchanged.

## Start here

- [[Project Attention Ranking]]: which ideas got the most time and thought.
- **Project hubs** (`00 Home/Projects`): one note per project or idea theme. Each links to every document that is mainly about it and every document that mentions it, down to the section where possible.
- [[Idea Index]]: every other idea found in the documents, A–Z. Many of these come from brainstorm lists.
- [[Design Topics]]: reusable mechanics and systems thinking, A–Z.
- [[Games Analysed]]: existing games that were deconstructed, analysed or modded.
- [[Big Five Intro]]: Ben's own umbrella for his biggest dream games.

## Folders

| Folder | What's in it |
|---|---|
| `10 Game Ideas` | Video game ideas, grouped by theme and then by project |
| `10 Game Ideas/Idea Collections` | Brainstorm dumps that hold many unrelated ideas (indexed in the hubs and in the Idea Index) |
| `20 Projects I Made` | Kobold, Emerge, Xenosurge, Pipe Game, Catastrophic Journey, game jams |
| `30 Tabletop` | D&D campaigns, one-shots and homebrew; other RPGs; wargames; board and card games |
| `40 Game Analysis` | Breakdowns of existing games |
| `50 Design Theory` | General design notes not tied to a single project |
| `60 Business & Funding` | Pitches, monetisation, studio notes (private financial documents are not included) |
| `70 Non-Game Ideas` | Apps, tools, websites, meetups |

## Note properties

Every note has frontmatter with these fields:

- `source`: original Drive path
- `modified`: last-modified date in Drive
- `type`, `area`, `status`
- `projects`: links to the hubs it belongs to
- `concepts`: every idea it contains
- `summary`
- `tags`

Notes that merged duplicate versions keep the most complete text, and add a **Differences from other versions** section at the end with the lines that existed only in the other copies.

## Not included

- Images, builds and media
- Google Docs comments, which contain other people's names
- Third-party material: rulebooks, published adventures, templates, other people's sheets
- Anything private: finances, funding applications, contracts, correspondence, other people's personal data
- Employer-internal documents
