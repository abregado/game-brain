**Pricing snowball (Factorio)**

- Product starts cheap, increases in price every time content is added

- All future updates are free

- Pros:

  - Promotes customers buying early

  - Keeps the community together

- Cons:

  - Has a limit before the price stops new players from trying the game (solvable with demo)

  - Loyal customers will buy immediately, reducing potential profits

**Major and Minor Expansions (Paradox Style)**

- Build the basic product with all placeholder systems complete

- Alternate between Major releases (one system overhaul) and Content/Bug Releases (updating all existing system content)

- Charge money for the Major release as DLC

- Offer “catch up” discount on previous paid DLC whenever a new Major release comes out

- Pros:

  - Customer pays for what they want

  - Less pressure to finish features (we get paid when the work is done)

  - Promotes proper development scope

- Cons:

  - Splits the community

  - DLC combinations slow down development exponentially

**Sequels (Command and Conquer)**

- Build a new game using the same engine

- Decide on new major features

- Port existing content from first game as needed

- Customer can buy the new game when it is ready

- Pros:

  - Larger swell in the hype wave

  - Can use existing early access model

  - Full price pre-order using early access model (more money up front)

- Cons:

  - Competing with yourself. Customers will inherently compare the new game with the previous one.

  - Development can easily go out of scope

  - Longer project time

  - Previous project still needs support, even though it is obsoleted

**  
  
Themed Small DLC (Witcher, Assassins Creed)**

- Release main game

- Decide on a theme and create new content based on that theme

- Engine upgrades go in the base game as a patch

- Content DLC available for a small price

- DLC optional per playthrough, similar to mods

- Pros:

  - Short development cycle

  - Data driven, we can see what is popular

  - Money for Releases

  - Can easily turn into a “sponsored modder donation service”

  - This is how most games do it

- Cons:

  - Looks like “Paid mod content” from the outside

  - Seen as greedy from the outside

  - Confusing for multiplayer games

**Standalone Expansion (Subnautica,Total War,Dawn of War)**

- Release main game

- Use same engine to create second product with different content

- Majority of new product is the same

- New product is different, not better in every way

- Pros:

  - Offers multiple entry points,

  - players may pick and choose content they are interested in,

  - yet also encourages them to purchase ALL content packs.

  - Get more hype than DLC.

  - Rapid development compared to true sequels as technology changes are typically minimal.

- Cons:

  - Longer development time and risk compared to DLC as the product must stand alone.

  - Only suitable for certain kinds of games where content can be readily pieced out without damaging the core product.

  - If the new product is improved on in every way and not unique enough this comes across as a poor sequel.
