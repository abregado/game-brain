Formats

List of resources in full screen overlay (every game ever)

- Grid with single unlimited stack per item type

List on side of screen toggleable (Rimworld)

Resource bar at top (Stellaris)

Bumpers to scroll categories left/right. Stick to navigate category up/down.

- Show one category on screen all the time

- Open full screen UX to see multiple categories

Questions

How to show categories?

Tricks

Horizon Zero - place relevant item counts “in-situ”



Longer text and number box next to each item









Prototypes

Full screen list. No selection of objects. Three categories, bumpers to cycle categories.

Full screen, list takes left 30%. One category. Select up down with stick. Change category with bumpers.

Full screen grid. Open with e or I. No selection of objects.

Side bar. Show category of last collected. Button to cycle. Button to lock.

Base proto.

Items have name, Icon and amount. Each has a category.

As soon as an item is found, show it and everything in its category as “discovered”

Show item name and category in world space on hover
