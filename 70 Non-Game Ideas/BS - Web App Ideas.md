Concept Description

collect coming meetups for multiple groups and display them all on one page. rate them

by number of attendees average over the last events per month. use images from meetup.

display stats for each included group

display member ratings based on attendance and how many groups they are involved in. Remove points for no showers.

constraints

- easily forkable

- no user accounts

- simple as possible

- client side if possible - POSSIBLE?

- ability to add any number of groups

- easily configurable without user accounts

- let site organiser choose the criteria for being included

Look?

Option 1

- Events displayed in grid, size shows attendance rate

- Colored pips for reaccuring events

Option 2

- Column per group, shows next events (not duplicates)

Benifits

- Exportable to other cities

- Gets out name on something

Tools for organisers

- Show days with lots of events publically so organisers can select good dates
