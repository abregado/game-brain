Two types of account, Banker and Client

All accounts can

Change password

Banker can set:

Daily/Weekly/Fourtnightly Allowance (per Client)

Daily/Weekly/Fourtnightly Bills (per Client) (automatic or optional)

Daily/Weekly/Fourtnightly Additional Jobs Checklist (per Client)

Payable Fines with Deadline

Instant Cash transfer/fine

interest rate on savings

Design the currency

the waiting period of savings withdrawals

Banker can enable/disable

Currency transfers between clients (global or per client)

Banker can View:

Each clients balance

Total state of the economy

Total cash in circulation

Checklist requests (jobs that clients claim to have done)

Client can

view transactions

view bills and fines

select when to pay bills and fines

transfer to other clients

request a withdrawal to real money

set up automatic movement of funds to savings

request a withdrawn from savings to spendings (takes X days)

**Additional Bloat Features**

**Bank Bonds**

Banker can generate “vouchers/bonds” which have a unique number on them

Banker can set the complexity of the bond hash (length, number or letters, words or random)

The system should generate codes and detect duplications

Banker sets the value when the voucher is created

These can be printed and given to a client

The clients have a “cash bond” options where they can put the number in

Extra points for using QR codes, barcodes, ect

**Bank Cards**

Using QR codes, each client can have a Bank Card. This can be used as additional account authentication (must be scanned on login)

**Additional Security Measures**

user can set a number of questions to be answered before transfers are completed

**Make it fun for the Clients**

Selectable banker/accountant avatars

drag and drop money between clients and the banker

Avatars for the bank/clients

Gamified interface (view your character in a bank, press on a character to interact)

Job Board with alerts, banker can notify clients that jobs need doing and offer special “rapid action” rewards
